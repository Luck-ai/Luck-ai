## 🚀 Featured projects

### 🖼 Computer vision & ML

| Project | What it does |
|---|---|
| 🎨 **[Vision-Edit](https://github.com/Luck-ai/Vision-Edit)** | Cross-platform .NET 8 + Avalonia image editor with SAM3 segmentation — runs on Desktop & Android |
| 🧪 **[YoloCraft](https://github.com/Luck-ai/YoloCraft)** | Local SAM2 tool for creating image-segmentation datasets to train YOLO models |
| 🔎 **[ocrpro](https://github.com/Luck-ai/ocrpro)** | Windows desktop OCR — pairs `Windows.Media.Ocr` with OpenCV preprocessing + ROI extraction |
| 🔊 **[spectral-bayes](https://github.com/Luck-ai/spectral-bayes)** | Audio classification with a from-scratch Gaussian Naive Bayes classifier + librosa spectral features |

### ⚙️ Embedded & robotics

| Project | What it does |
|---|---|
| ⚡ **[motorpilot](https://github.com/Luck-ai/motorpilot)** | STM32 firmware: Field-Oriented Control for BLDC motors over Modbus RTU / RS-485 |
| 🌫 **[airlink](https://github.com/Luck-ai/airlink)** | Dual-ESP32 air-quality monitor over ESP-NOW — sensor pod sends, display pod warns |
| 👋 **[wavedrive](https://github.com/Luck-ai/wavedrive)** | Wave at a webcam to drive an ESP32 Wi-Fi robot (MediaPipe + TFLite + TCP) |
| 🦾 **[kinematics-matlab](https://github.com/Luck-ai/kinematics-matlab)** | MATLAB library for robot-arm forward / inverse kinematics + the Jacobian + trajectory generation |

### 🌐 Web & data

| Project | What it does |

| 📦 **[optistock](https://github.com/Luck-ai/optistock)** | Dockerized fullstack web app for stock inventory & purchase orders, with SendGrid email |
| 🔁 **[stockflow](https://github.com/Luck-ai/stockflow)** | Python ETL pipeline that ingests sales / SKU / stock data into PostgreSQL |
